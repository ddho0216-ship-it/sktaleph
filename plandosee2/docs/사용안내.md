# 플랜두씨 다이어리 2 사용 안내

1. https://planloop-study.ddho0216.chatgpt.site 에 접속하고 회원가입합니다. 다른 서비스의 실제 비밀번호는 쓰지 않습니다.
2. 로그인 → 계정·백업 → `플랜두씨_기존기록_가져오기.json` 파일을 선택합니다. 비어 있는 계정에서만 가져올 수 있습니다.
3. 기존 계획·할 일·실행·수정 이력을 확인합니다. 계획 세우기에서 날짜 등 본인 계획을 조정할 수 있습니다.
4. 매일 실제 공부가 끝난 뒤 '5일, 나의 공부를 관찰하기'에 공부 시간(분)과 실제로 한 일을 적습니다. 실제 기록 날짜는 Asia/Seoul의 오늘로 서버에서 정합니다.
5. 1·2일차는 긴 할 일부터 시작합니다. 2일차 다음 날짜에, 3일차 기록을 쓰기 전에 '규칙 바꾸기'에서 규칙과 1·2일차에 근거한 이유를 입력합니다.
6. 3~5일차는 바꾼 규칙으로 실행합니다. 같은 지표와 단위를 유지합니다. 평균이 나빠져도 그대로 보관합니다.
7. 5일을 마치면 계정·백업에서 전체 자료를 내보내고 설명서의 실제 관찰 항목을 채웁니다. 화면의 합계·평균과 직접 더한 값을 대조합니다.

오늘(2026.10.01)을 1일차로 시작한다면 2일차는 10.02, 규칙 변경은 10.03의 3일차 기록 전, 5일차는 10.05입니다. 실제 사용하지 않은 날짜를 채우지 않습니다.

## 현재 상태

- 인증과 계정별 자료 차단은 구현했습니다. API 검증 결과는 설명서와 증거 JSON에 있습니다.
- 기존 공개 기록은 14개 할 일·7개 실행·4개 계획 이력이 있는 파일로 보관했습니다. 실제 본인 계정으로 가져오기는 사용자가 로그인한 뒤 진행합니다.
- 실제 서로 다른 날짜의 5일 사용 기록, 실제 규칙 변경 및 전후 비교는 아직 없습니다. 합성 테스트 결과는 실제 사용 증거로 제출하지 않습니다.
- 최종 제출 전 `AI와 나` 및 `내 판단` 문장은 본인이 검토하고 본인의 판단으로 확정해야 합니다.

## 확인 방법 4줄

어디로 가나요: 결과물 URL을 열면 로그인 화면이 보입니다. 소스 URL은 `/source.html`입니다.
세 단계 안에 무엇을 하나요: 가입 → 로그인 → 내 계정에 할 일을 추가합니다.
무엇이 보이면 통과인가요: 로그인 후 내 자료만 보이고, 로그아웃 후 자료 화면에서 로그인 화면으로 이동합니다.
안 될 때는 무엇이 보이나요: 로그인하지 않은 직접 API 요청은 401, 다른 계정의 자료 ID는 404와 일반 오류 문구가 나옵니다.

## 제출 전 보완

- 설명서에 실제 본인 계정의 가져오기 성공, 실제 5일 기록, 실제 규칙 변경 시각·이유, 전후 평균, 직접 계산 대조를 추가합니다.
- 비밀번호·세션 쿠키·토큰 원문은 제출하지 않습니다.
- 제출 파일 및 웹 첫 화면 검증을 완료한 다음 최종 제출합니다.
